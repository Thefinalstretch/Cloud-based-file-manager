This then creates mock save files for the game Lego Batman 3 Beyond Gotham

Testing:
Open the program.
Select Upload Game-Save.
Choose Lego Batman 3 between the found games.
Select the two available files.
Press Upload.
Then go back to home screen.
Go into Download Game-Save.
Choose Lego Batman 3 between the found games.

Expected Result:
Only one file has been uploaded. Meaning our duplicate handling has failed,
one file has overwritten the other.

This is because a bug in our asynchronous function that makes it so
if two files are uploaded in a batch, results in one overwritten the other.
Uploading the two files seperately works, making one file go to index 0 and the other to index 1.
